Authentication Architecture

Recommended: Hybrid Approach

Approach: AWS Cognito + JWT Tokens

Cognito handles user registration, login, password reset, MFA, and social login. API Gateway validates JWTs. Lambda functions receive user identity in context.

Cognito Manages:

  • ✓ User registration / login
  • ✓ Password reset / recovery
  • ✓ Email verification
  • ✓ MFA (TOTP/SMS)
  • ✓ Social login (Google/Facebook)
  • ✓ Token lifecycle

Your Code Manages:

  • ✓ Business logic only
  • ✓ User profile data (PostgreSQL)
  • ✓ Content permissions
  • ✓ Custom claims (if needed)

User Migration Strategy

RECOMMENDED

Password Reset Approach

  • 1. Export WordPress users (email, username)
  • 2. Import to Cognito with FORCE_CHANGE_PASSWORD status
  • 3. Users receive "set password" email on first login
  • 4. No password hash migration needed
Pros: Simple, secure, no hash compatibility issues
ALTERNATIVE

Seamless Migration

  • 1. Lambda trigger on Cognito sign-in
  • 2. Check WordPress DB for password hash
  • 3. Validate against old hash format
  • 4. Silently migrate to Cognito
Pros: No user action required. Cons: More complex
