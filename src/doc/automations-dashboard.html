Cross-timeframe duplicate videos (Movies playlist)
The same video can appear in multiple timeframe buckets and be added twice. get_popular_videos_by_timeframe() deduplicates per-timeframe but not across all timeframes before final add. Fix: collect all candidate IDs first, deduplicate globally, then add.
