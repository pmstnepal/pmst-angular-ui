PMST Color Palette

This palette uses off-white background with strategic use of #fe5252 (brand color) for psychological brand identity.

Primary Colors

Section Background
#e5e7eb (--pmst-bg-light)
All section backgrounds, button backgrounds, card borders, search input border
Hero Background

Hero section background, active tab background
Text Primary
#4a4a6a
All body text, headings, titles, card text, links — replaces #1a1a2e globally
Text Light
#6b7280
CTA hero text, metadata, supporting text
Text Dark (Deprecated)
#1a1a2e
Fully replaced by #4a4a6a. Do not use.

Color Usage Guidelines

  • #fe5252 (Brand Color): Tab text, button labels, icon highlights, glow effects. Not for large text or backgrounds.
  • #ff6b6b (Brand Hover): Hover state for any #fe5252 element. Card glow box-shadow.
  • #e5e7eb (Section BG / Button BG): All section backgrounds, button backgrounds, card borders, search input borders.
  • #d1d5db (Hero BG / Active Tab): Hero section background, active tab background, borders.
  • #4a4a6a (Text Primary): All headings, body text, titles, links. Replaced #1a1a2e globally.
  • #6b7280 (Text Light): CTA hero text, metadata, supporting text.
  • #1a1a2e: Deprecated — replaced by #4a4a6a. Do not use in new code.
